# Plan: n8n Webhook Email Workflow

## Workflow Overview
Mengirim email ke user yang terdaftar di database berdasarkan trigger webhook. Email menggunakan template yang dibuat di n8n.

## nodes yang diperlukan
1. **Webhook** - Trigger untuk menerima request
2. **Database Node** (Postgres/MySQL/Airtable/Google Sheets) - Untuk mengambil data user
3. **Email Send / Gmail** - Untuk mengirim email dengan template
