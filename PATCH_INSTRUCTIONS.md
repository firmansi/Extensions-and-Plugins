# Patch Native Tool Calling untuk Google Gemini Pipeline v1.16.2

## Masalah
Pipeline v1.16.2 tidak bisa menggunakan native tools OpenWebUI karena:
1. Saat Gemini return `function_call`, pipeline membuang `tool_calls` dan hanya return text content (string)
2. Pipeline menjalankan `_run_tool_loop()` sendiri alih-alih mendelegasikan ke OWUI
3. Streaming dimatikan paksa saat tools detected

## Fix (3 perubahan kecil di method `pipe()`)

Buka function Google Gemini Pipeline di Admin > Functions, lalu edit kode-nya:

### Perubahan 1: Hapus blok "disable streaming saat tools detected"

Cari kode ini (sekitar line 3026-3041):
```python
            native_tools = self._get_native_tools_from_config(generation_config)
            has_native_tools = (
                bool(native_tools) and self.valves.NATIVE_TOOL_CALLING_ENABLED
            )
            if has_native_tools and stream and not supports_image_generation:
                stream = False
                await __event_emitter__(
                    {
                        "type": "status",
                        "data": {
                            "action": "tool_mode",
                            "description": "Native tools detected; switching to non-streaming mode for server-side execution.",
                            "done": True,
                        },
                    }
                )
```

**Ganti dengan:**
```python
            has_tools = bool(__tools__) and self.valves.NATIVE_TOOL_CALLING_ENABLED
```

### Perubahan 2: Hapus kondisi yang disable streaming + hapus _run_tool_loop call

Cari kode ini (sekitar line 3043-3098):
```python
            if stream:
                if supports_image_generation:
                    stream = False
                elif has_native_tools:
                    stream = False
                else:
                    try:
```

**Ganti dengan:**
```python
            if stream and not supports_image_generation:
                try:
```

Lalu cari kode ini (sekitar line 3090-3098):
```python
                    if has_native_tools and not supports_image_generation:
                        response, _ = await self._run_tool_loop(
                            client,
                            model_id,
                            contents,
                            generation_config,
                            native_tools,
                            __event_emitter__,
                        )
                    else:
                        response = await self._retry_with_backoff(get_response)
```

**Ganti dengan:**
```python
                    response = await self._retry_with_backoff(get_response)
```

### Perubahan 3: Return tool_calls dalam format OpenAI-compatible (INI YANG PALING PENTING!)

Cari kode ini (sekitar line 3256-3291):
```python
                    if not content:
                        if has_native_tools:
                            content = "Proses eksekusi fungsi telah selesai."
                        else:
                            content = (
                                "[Tidak ada respon teks yang dihasilkan oleh model]"
                            )

                    if __event_emitter__:
                        await __event_emitter__(
                            {
                                "type": "chat:message",
                                "data": {
                                    "role": "assistant",
                                    "content": content,
                                    "done": True,
                                },
                            }
                        )

                    usage = self._build_usage_dict(
                        getattr(response, "usage_metadata", None)
                    )

                    message_data = {"role": "assistant", "content": content}

                    if tool_calls:
                        message_data["tool_calls"] = tool_calls

                    result = {
                        "choices": [{"message": message_data}],
                    }
                    if usage:
                        result["usage"] = usage

                    return content
```

**Ganti dengan:**
```python
                    if not content and not tool_calls:
                        content = "[No text response generated by the model]"

                    usage = self._build_usage_dict(
                        getattr(response, "usage_metadata", None)
                    )

                    # FIX: Return tool_calls in OpenAI format so OWUI can execute them
                    if tool_calls:
                        message_data = {"role": "assistant", "content": content or ""}
                        message_data["tool_calls"] = tool_calls
                        result = {"choices": [{"message": message_data}]}
                        if usage:
                            result["usage"] = usage
                        return result

                    if __event_emitter__ and content:
                        await __event_emitter__(
                            {
                                "type": "chat:message",
                                "data": {
                                    "role": "assistant",
                                    "content": content,
                                    "done": True,
                                },
                            }
                        )

                    return content
```

### Perubahan 4 (Opsional): Gunakan Gemini's native function call ID

Cari kode ini (sekitar line 3131-3144):
```python
                        if getattr(part, "function_call", None):
                            fc_args = self._normalize_function_args(
                                getattr(part.function_call, "args", None)
                            )
                            tool_calls.append(
                                {
                                    "id": f"call_{uuid.uuid4().hex[:8]}",
                                    "type": "function",
                                    "function": {
                                        "name": part.function_call.name,
                                        "arguments": json.dumps(fc_args),
                                    },
                                }
                            )
```

**Ganti dengan:**
```python
                        if getattr(part, "function_call", None):
                            fc_args = self._normalize_function_args(
                                getattr(part.function_call, "args", None)
                            )
                            fc_id = getattr(part.function_call, "id", None)
                            if not fc_id:
                                fc_id = f"call_{uuid.uuid4().hex[:8]}"
                            tool_calls.append(
                                {
                                    "id": fc_id,
                                    "type": "function",
                                    "function": {
                                        "name": part.function_call.name,
                                        "arguments": json.dumps(fc_args),
                                    },
                                }
                            )
```
